# Navy Notes

A OneNote-style note-taking application with a navy blue theme built with Electron.

## Features

- Organize notes in notebooks and sections
- Rich text editing with formatting options
- Navy blue theme throughout the interface
- Import and export functionality
- Automatic saving
- Cross-platform desktop application

## Installation

### Prerequisites

- [Node.js](https://nodejs.org/) (v14 or later)
- [npm](https://www.npmjs.com/) (v6 or later)

### Setup

1. Clone or download this repository
2. Navigate to the project directory
3. Install dependencies:

```bash
npm install
```

4. Start the application:

```bash
npm start
```

## Building Standalone Applications

### Windows:

```bash
npm run package-win
```

### MacOS:

```bash
npm run package-mac
```

### Linux:

```bash
npm run package-linux
```

The packaged applications will be available in the `release-builds` directory.

## Usage

- Create notebooks to organize your notes
- Add notes within notebooks
- Use the rich text editor to format your content
- Notes are automatically saved as you type
- Export and import your notes using the File menu
